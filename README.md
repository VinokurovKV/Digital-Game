# «Ну, погоди!» — электронная игра

Веб-версия классической игры серии «Электроника». Игрок управляет Волком, ловит падающие яйца и старается установить новый рекорд. Проект адаптирован для компьютеров, планшетов и телефонов.

## Возможности

- режимы «Игра А» и «Игра Б» с разным количеством дорожек и скоростью;
- управление клавиатурой, мышью и касаниями;
- постепенное ускорение, подсчёт очков и ошибок;
- сохранение рекорда в `localStorage`;
- пауза с обратным отсчётом;
- звуковые эффекты и анимация разбитых яиц;
- выключение LCD-экрана с эффектом помех;
- режим часов с автоматической демонстрацией игры;
- адаптивная полноэкранная вёрстка.

## Правила игры

Игра начинается после нажатия кнопки `ИГРА А` или `ИГРА Б`.

- В игре А яйца появляются на трёх дорожках. Верхняя левая дорожка с Зайцем не используется.
- В игре Б задействованы все четыре дорожки и установлен более высокий начальный темп.
- За каждое пойманное яйцо начисляется одно очко.
- При промахе скорость сбрасывается до начального значения.
- После пяти пропущенных яиц игра заканчивается и показывается итоговый счёт.
- Новый рекорд сохраняется после окончания партии.

## Управление

| Положение Волка | Клавиша |
| --------------- | ------- |
| Слева сверху    | `Q`     |
| Слева снизу     | `A`     |
| Справа сверху   | `P`     |
| Справа снизу    | `L`     |

Вместо клавиатуры можно использовать четыре круглые кнопки на корпусе приставки. На телефоне рекомендуется горизонтальная ориентация экрана.

- Повторное нажатие активной кнопки режима или `Esc` ставит игру на паузу.
- Для продолжения нужно ещё раз нажать активную кнопку режима. Игра возобновится после обратного отсчёта.
- Кнопка `ЭКРАН` выключает или включает LCD-экран и сбрасывает текущую партию.
- Кнопка со значком динамика включает и отключает звук.
- Кнопка со значком часов запускает автоматический режим с отображением текущего времени.

## Запуск

```bash
npm ci
npm run dev
```

Приложение будет доступно по адресу <http://localhost:8080>.

## Основные команды

```bash
npm test          # тесты
npm run build     # сборка
npm run lint      # ESLint
npm run format    # Prettier
npm run check     # все проверки, тесты и сборка
```
